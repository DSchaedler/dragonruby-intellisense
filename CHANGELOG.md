# Change Log

All notable changes to the DragonRuby Intellisense extension will be documented here.

## [0.0.1] - 2026-10-03

### Added

- Ruby completions and snippets for DragonRuby GTK APIs, including editable parameter placeholders.
- Context-aware suggestions for common `args` APIs, inputs, outputs, render targets, and helper classes.
- Hover descriptions and signature help for completion items.
- An optional workspace API scan that can discover additional API calls from DragonRuby documentation.
- A DragonRuby-inspired extension icon and initial Marketplace documentation.
